# Javalin example app

[![Java CI](https://github.com/hexlet-components/java-javalin-example/actions/workflows/build.yml/badge.svg)](https://github.com/hexlet-components/java-javalin-example/actions/workflows/build.yml)

Code from the lessons of the Hexlet course «Java: Веб-технологии», combined into a single Javalin application: routes and named routes, controllers, DTO pages, jte templates with a layout, flash messages, sessions and repositories. Lessons show these pieces one at a time, here they work together.

## Requirements

- JDK 27
- Gradle 9.7.1 (the wrapper downloads it)

## Usage

```bash
make install
make start
```

Open in browser: <http://localhost:7070>
